# SWITS


> SoftWare Integration Test Specification 소프트웨어 통합 테스트 명세서  
>   
> 각 유닛들을 연결했을 때 서로 정상적으로 통신하고 동작하는지 확인하는 테스트.  
> RPi ↔ Arduino, STM32 통신, ROS 2 토픽 흐름, 시나리오 기반 기능 연동을 검증.
