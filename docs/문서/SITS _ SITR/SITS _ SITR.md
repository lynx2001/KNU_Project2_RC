**2.** 통합 전략 **(Integration Strategy)**


**2.1** 통합 접근 방법


본 시스템은 **SAD**에 정의된 **3**계층 구조를 기반으로 **Bottom-Up(**상향식**)** 통합 전략을 채택한다**.** 하위 레벨의 하드웨어 인터페이스 및 단위 노드부터 검증한 후**,** 점진적으로 상위 레벨의 통합 시나리오로 확장하여 통합의 안정성을 확보한다**.**


**2.2** 통합 단계 **(Integration Levels)**


| 단계     | 통합 레벨           | 통합 대상                            | 주요 검증 항목                                      |
| ------ | --------------- | -------------------------------- | --------------------------------------------- |
| **L1** | 전원 분배 통합        | 배터리, 퓨즈, 스위치                     | 전압 안정성, 전류 용량, 공통 GND                         |
| **L2** | **HW** 인터페이스 통합 | RPi↔STM32, 
RPi↔Arduino
STM32↔모터 | USB 직렬(UART), PWM 신호, GPIO 매핑                 |
| **L3** | 센서**/**구동부 통합   | LiDAR, Camera, 초음파, 구동/조향 모터     | 센서 데이터 정확도, 액추에이터 응답성                         |
| **L4** | **SW** 노드 통합    | ROS 2 노드 간 토픽 발행/구독              | /cmd_vel, /scan, /image_raw, /ultrasonic_data |
| **L5** | 시스템 통합          | 전체 HW + SW + 안전 계층 통합            | E2E 자율주행, PAS 동작, 장시간 안정성                     |


**2.3** 통합 환경


**2.3.1** 하드웨어 환경

- 자율주행 RC카 플랫폼 (3계층 물리 구성)
- 전원: 11.1V 5000mAh 3S Li-Po 배터리 (완충 상태)
- 측정 장비: 디지털 멀티미터
- 시험 환경: 실내 시험 트랙

**2.3.2** 소프트웨어 환경

- Raspberry Pi 4: Ubuntu 22.04 LTS, ROS 2 Humble
- STM32: STM32CubeIDE 기반 펌웨어, FreeRTOS
- Arduino Mega: Arduino IDE 기반 C 펌웨어
- 디버깅: rqt_graph, rqt_plot, ros2 topic echo, PuTTY

**2.4** 통과**/**실패 판정 기준


| 판정                   | 기준                                         |
| -------------------- | ------------------------------------------ |
| **Pass (**통과**)**    | 기대 결과와 실제 결과가 일치하며, ICD에 명세된 모든 허용 오차 내 동작 |
| **Fail (**실패**)**    | 기대 결과와 다르거나, 허용 오차를 초과하거나, 시스템 다운/리셋 발생    |
| **Conditional Pass** | 주요 기능은 동작하나 부가 항목 미달성 - 영향도 분석 후 결정        |
| **N/A**              | 선행 테스트 실패로 수행 불가 또는 적용 대상 외                |
